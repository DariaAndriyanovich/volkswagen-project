# Volkswagen Project

This is a simple educational website built with HTML and CSS that compares two popular Volkswagen models: **Passat** and **Golf**.

## 🔗 Live Demo
👉 [Open the site](https://DariaAndriyanovich.github.io/volkswagen-project/)

## 📌 Features
- Clear layout and structure with HTML5
- Custom CSS styling and image gallery
- Tables, external links, and YouTube video embed
- Responsive layout using flexbox and semantic elements

## 🛠 Technologies Used
- HTML5
- CSS3
- Visual Studio Code
